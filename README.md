# Multi-Agent Research Assistant

A Streamlit app that turns a research topic into a sourced report. Specialized LangChain agents search the web and extract article content; a writer produces the report, and a critic reviews it.

## Features

- Search the web for relevant sources with Tavily.
- Extract readable article content from selected pages.
- Generate a structured report with an Ollama-hosted language model.
- Review the report with a separate critic chain.
- View pipeline progress and download the report as Markdown.

## Requirements

- Python 3.11 or newer
- [Ollama](https://ollama.com/) installed and running locally
- A [Tavily API key](https://tavily.com/)

The default model is `qwen3:8b`. Pull it before running the app:

```bash
ollama pull qwen3:8b
```

## Installation

Clone the repository and enter its directory:

```bash
git clone https://github.com/Arulkumar22/Langchain-MultiAgent-Research_System.git
cd Langchain-MultiAgent-Research_System
```

Create and activate a virtual environment:

```bash
python -m venv .venv
```

On macOS or Linux:

```bash
source .venv/bin/activate
```

On Windows PowerShell:

```powershell
.\.venv\Scripts\Activate.ps1
```

Install the Python dependencies:

```bash
python -m pip install --upgrade pip
pip install -r requirements.txt
```

Create a `.env` file in the project root and add your Tavily key:

```dotenv
TAVILY_API_KEY=your_tavily_api_key
```

Keep `.env` private; it is excluded from version control.

## Run

Make sure Ollama is running and the `qwen3:8b` model is available, then start Streamlit:

```bash
streamlit run app.py
```

Open the local URL printed by Streamlit, enter a research topic, and select **Run Research Pipeline**.

## Architecture

```text
Research topic
      |
      v
Streamlit UI (app.py)
      |
      v
Search agent -----> Tavily web search
      |
      v
Reader agent -----> Scrape and extract selected page
      |
      v
Writer chain -----> Structured research report
      |
      v
Critic chain -----> Score and improvement feedback
      |
      v
Display results and offer Markdown download

Search agent, reader agent, writer, and critic all use Ollama (qwen3:8b).
```

The search agent uses Tavily to find sources. The reader agent selects a relevant result and extracts its page content. The writer and critic are LangChain prompt/model/output-parser chains. The Streamlit app coordinates these sequential stages and presents the intermediate results, final report, and critique.

## Technology

- **Python** — application and pipeline
- **Streamlit** — web interface
- **LangChain** — tool-using agents and report/critique chains
- **Ollama + Qwen3 8B** — local language model
- **Tavily** — web search
- **Requests, Trafilatura, Readability, Beautiful Soup, and lxml** — page fetching and content extraction
- **python-dotenv** — local environment configuration

## Notes

Research output is generated by an AI model and may contain errors. Verify important claims and sources before relying on or sharing a report. Web search requires Tavily access; model inference uses your local Ollama installation.
